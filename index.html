About

This is the Price family parks tracker, built for Levi, Lucy, Rockwell, and Asher.

The site reads from a single data.json file in this site's GitHub repository. To log new visits, the family admin opens the site with ?admin=1 at the end of the URL, makes changes, exports the new JSON, and pastes it into GitHub. All visitors see the latest data automatically.
